# ✨ Random Motivational Quote Generator ✨

## Overview
The **Random Motivational Quote Generator** is a lightweight desktop application built with Python. Designed as a quick hackathon mini-project, it utilizes a graphical user interface (GUI) to present users with a curated list of uplifting and inspirational quotes to provide a quick dose of daily motivation.

## Features
* **Simple GUI:** Built using Python's standard `tkinter` library, featuring a clean, light-blue background and readable typography.
* **Randomized Selection:** Uses the `random` module to pull and display quotes from a built-in collection of motivational sayings.
* **Interactive Button:** Includes a prominent "Show New Quote" button that allows users to instantly refresh the text on the screen.
* **Auto-Start Functionality:** Automatically displays a fresh quote the moment the application window is launched.

## Technologies Used
* **Language:** Python 3.x
* **Libraries:** `tkinter` (GUI), `random` (Logic)
